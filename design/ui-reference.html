UI Reference

Every screen of thehallucinatedlab.space in one standalone file — navigation, home, the tool index and a tool, pipelines, the assistant, solutions, media, the notes board, artifacts, the dev-status pages, the sitemap and the 404.

There is no JavaScript here and nothing is fetched. The site's moving parts — the theme toggle, the mobile drawer, the app-preview tabs, the typing cursor, the fade-in-on-scroll — are drawn in their resting state, and where a state only exists after a click, both states are laid out next to each other.

Extract

Documents to Markdown with the structure still attached. Headings stay headings and pages stay marked, because that is what the next stage splits on.

  • takes PDF, DOCX, PPTX, XLSX, EPUB, HTML

  • needs the local Python package

Splits a Markdown document along its own heading structure rather than at arbitrary offsets, so a chunk is still a thought.

  • writes chunks.jsonl you can read

Pipelines

/pipelines.html

Two pipelines, then the argument for the shape: every stage writes a file, so the middle of a run is something you can read rather than something you have to trust.

thehallucinatedlab.space/pipelines.html pipelines.html
Run The Whole Thing

Pipelines

A tool does one thing. A pipeline runs several of them in the order that actually gets you somewhere — and writes every stage to disk on the way.

Four stages

RAG

A document in, a searchable index out. Extract, chunk, embed, index — the same four tools you can run yourself, in the order that gets you there.

  • one command thl pipeline rag report.pdf
  • every stage on disk — read the chunks, not just the answer
  • resumable a stop keeps what it made
How RAG runs
Five stages

EDA

A table in, a report you can hand to someone out — with the figures, a replayable recipe, and the Python script that produced all of it.

  • one command thl pipeline eda sales.csv
  • reproducible the recipe replays every choice
  • five primitives each callable on its own
Open EDA
Pipeline · RAG

extract → chunk → embed → index

Stage 01

extract

PDF, DOCX, PPTX or EPUB to Markdown, with headings and page boundaries intact.

Stage 02

chunk

Splits on that structure, not on a character count, and writes chunks.jsonl.

Stage 03

embed

BGE-M3 at 1024 dimensions, or all-MiniLM-L6-v2 at 384. Local either way.

Stage 04

index

Vectors and chunks into a portable directory you own — Chroma, or plain numpy.

Running it

$ thl pipeline rag report.pdf --out ./index [1/4] extract report.pdf → report.md 41 pages [2/4] chunk report.md → chunks.jsonl 318 chunks [3/4] embed chunks.jsonl → vectors.npy 318 × 1024 [4/4] index vectors.npy → ./index/ chroma

What a stopped run looks like

$ thl pipeline rag report.pdf --out ./index [1/4] extract ✓ report.md [2/4] chunk ✓ chunks.jsonl [3/4] embed ✗ interrupted — 212/318 embedded, vectors.partial.npy kept resume with: thl pipeline rag report.pdf --resume

Dictionary / AI & Mathematics

Attention Mechanism

/əˈtɛnʃən ˈmɛkəˌnɪzəm/ at·ten·tion mech·a·nism noun
Deep Learning Core

Definition

1.[in deep learning] a layer that produces each output as a weighted blend of all available inputs, where the weights are computed from the similarity between a query and a set of keys.

The attention mechanism let the decoder consult any source token instead of a single fixed summary vector.

Formal statement

Attention(Q,K,V) = softmax(Q K^T / sqrt(d_k)) V

Division by sqrt(d_k) keeps the dot products in a range where softmax gradients do not vanish.

Synonyms

  • soft alignment sense 1 · Near

  • Softmax
  • Embedding
