01 / Approach

How the lab works

We don't jump to "AI". A problem is diagnosed before anything is built, and what gets built is measured against the problem before it ships.

  2. Problem

    What isn't working, stated plainly, with the data and the constraints around it.

  3. Audit

    Where the time, the error or the cost actually comes from — measured, not assumed.

  4. Determine

    Software, ML or AI: whichever the problem needs. Often it is the first one.

  5. Build

    Small, local-first, and on your infrastructure wherever that is possible.

  6. Verify

    Checked against the problem statement, not against a demo.

02 / Determine

What does your problem actually need?

Three kinds of system, three kinds of answer. Picking the right one is most of the work.

Deterministic. Fast. Reliable.

When the rules are known, write the rules. A scheduler, a pipeline, a converter that runs in a browser tab — no model, no inference cost, and the same answer every time.

  • Timetabling and constraint solving
  • Data pipelines and format conversion
  • Tooling, dashboards, integrations
RULESCODERESULT

Pattern-driven. Predictive. Data-dependent.

When nobody can write the rule but the data holds it. A model learns the pattern, and its answer is only as good as the data it saw — so the audit comes first.

  • Forecasting, scoring, anomaly detection
  • Classification of documents, images, events
  • Recommendation and ranking
DATAMODELPREDICTIONVALIDATION

Language. Reasoning. Generation.

When the input is language and the output has to be too. A language model, retrieval around it, and validation after it — running locally where the data is sensitive.

  • Question answering over your own documents
  • Drafting, summarising, extracting structure
  • Assistants that run a tool from a plain sentence

Every tool on this site runs in the tab that opened it. There is no server we operate, no analytics and no third-party origin — the content-security policy on every page says so, and a test fails the build if it changes.
