Open Data

Datasets

The sets the lab builds to measure its own tools, published with the provenance and the licence attached.

Every tool on this site makes a claim — that a splitter respects a code fence, that an extractor keeps the text a reader wants, that a converter survives a ragged table. A claim you cannot measure is marketing. These are the sets the lab is assembling to measure them, and the intent is to publish each one rather than keep the scoreboard private. A dataset without a stated origin and a stated licence is not publishable, so both are on the card before anything is released.

Chunk boundaries

Assembling

Long documents with the split points a person would actually choose, marked by hand. It exists to answer one question about the Chunk tool that unit tests cannot: not whether a chunk fits the budget, but whether cutting there destroyed the meaning.

Converter round trips

Planned

Nothing here is downloadable yet. These four are the sets currently being assembled; the cards describe what each one is for and what it will carry, not something you can fetch today. A set is published when its provenance is written down, its licence is settled, and the scores the lab quotes from it can be reproduced by someone else — and if a set cannot clear that, the card comes down instead of shipping numbers nobody can check.

The rules each set is built under

These are constraints on what may go into a set at all, not preferences. A set that breaks one of them does not get published late — it gets rebuilt.

Provenance before content

Every record names where it came from. Material whose licence cannot be established does not go in, however useful it looks, and nothing is collected by scraping a site that asked not to be scraped.

No personal data, at any size

No names, addresses, contact details or anything else that identifies a person. This is a floor, not a target: a set that would need anonymising is the wrong set to have built.

Fetchable without an account

Each set ships as plain JSONL or CSV plus a checksum, small enough to read with the tools already on this site. The intended shape of a release, once the first one lands:

thl-chunk-bounds/
├── data.jsonl        # the records
├── SHA256SUMS        # checksum for every file above
├── LICENCE           # CC BY 4.0, full text
└── DATASHEET.md      # origin, method, known limits, what it cannot measure
