On The Bench

Data

The dataset half of the toolkit — what already runs in the page, and what is still being built.

Every tool here holds the same line the rest of the site does: the file stays on the machine that opened it. A dataset is the case where that matters most — it is usually the thing you are least willing to paste into a hosted box. Profiling already ships and runs entirely in the browser; the rest of this page is work in progress, which is why it sits behind dev mode.

Describe a dataset, profile one column, plot it, and score how two columns relate. Five tools, all running on the page against a file you never upload. This is the one part of the data workbench a visitor can already use.
