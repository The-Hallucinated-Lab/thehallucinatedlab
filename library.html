Packages in the THL Library

Browser · Python Live

Convert

Change an image between PNG, JPEG, WebP and AVIF without uploading it anywhere.

The same tool through three doors: a page that runs on a canvas, a plain-english request to the assistant, and thl convert in a terminal. One spec describes the arguments, so all three take the same ones and cannot drift apart.

format png, jpeg, webp or avif. Required.
quality 1-100 for the lossy formats. Defaults to 92.
Open Convert thl convert photo.jpg --format webp --quality 70
Python · CLI Live

Exploratory Data Analysis

Point it at a data file. Get back a report you can read, the figures behind it, and the script that produced them.

Five primitives — describe, profile, plot, relate, report — plus thl eda, which drives them as a session. Every run writes a recipe of the decisions it made, so a rerun matches and a colleague gets the same numbers. Unlike the browser tools this one is Python only, on purpose: profiling a 200 MB CSV on a canvas is not something the browser runtime should attempt, and the spec says so rather than rendering a form that would fail.

analysis.py Regenerates the whole report, and is meant to be edited.
confidence Column types below 0.7 are flagged, never asserted.
Open Exploratory Data Analysis thl eda sales.csv --target churn

Contributed by @06pratyush — source at thl-exploratory_data_analysis_in_CLI.

The RAG Pipeline

Documents to a Vector Database

Five tools that take a document to a database you own and can query with your own code. Each runs on its own; together they are a pipeline. Every heavy dependency is an optional extra, so the base install stays small.

Pipeline stage 1

Extract

PDFs, Word files, slides, spreadsheets and e-books into Markdown that keeps its headings and page boundaries.

  • in the browser text, markdown, html and csv, unaided
  • with the package pdf, word, slides, sheets, epub, rtf, odt, eml
  • never invented no outline in the PDF means no headings
Open Extract
Pipeline stage 2

Chunk

Splits along the document's own headings rather than every 512th character, so a chunk is a section and not a window.

  • citable every chunk carries its heading path and page
  • jsonl one record per line, greppable and streamable
  • sized against the tokenizer the embedder actually uses
Open Chunk
Beside the pipeline

Tokenize

How big is this and what will it cost to embed — including which pieces would be silently truncated.

  • distribution median, 95th, and the long tail
  • overflow what exceeds the context window
  • three counters exact, OpenAI, or no download at all
Open Tokenize
Pipeline stage 3

Embed

Chunks to vectors on your own machine. BGE-M3 at 1024 dimensions, or MiniLM at 384 when speed matters more.

  • normalised so cosine and dot product agree
  • one file a single .npy, not one per chunk
  • no prefix BGE-M3 wants none, unlike bge-large-en
Open Embed
Pipeline stage 4

Index

A portable database directory you own, as Chroma or as plain numpy, with everything needed to reopen it.

  • self-describing records the model, dimensions and normalisation
  • query snippet written alongside, so it is usable immediately
  • no pickle FAISS is skipped for exactly that reason
Open Index

Installing the pipeline

Every stage is a method in the same package and a subcommand of the same CLI. The parsers, tokenizers and the embedding model are optional extras, so installing the package does not drag in torch for someone who only wanted to convert an image.

One stage at a time
pip install "thehallucinatedlab[extract]" pip install "thehallucinatedlab[chunk]" pip install "thehallucinatedlab[embed]" pip install "thehallucinatedlab[index]"
Or the whole pipeline
pip install "thehallucinatedlab[rag]" thl extract report.pdf thl chunk report.md --max-tokens 512 thl embed report.jsonl thl index report.npy report.jsonl mydb
