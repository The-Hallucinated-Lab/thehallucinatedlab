Local AI Assistant

Chat connects to Ollama running on your machine. No API keys, no cloud, no data leaves your device. Completely local.

Tools need none of this. Converting an image is understood and run right here in the page — you only need Ollama for open-ended conversation.

1
Install Ollama from ollama.com
2
Pull a model — recommended: ollama pull gemma4:e4b
Any installed model works; the page picks the first one it finds.
3
Allow the page to talk to Ollama (CORS). Set this before starting Ollama:
Local dev (file:// or localhost):
setx OLLAMA_ORIGINS "*"  (Windows)
export OLLAMA_ORIGINS="*"  (macOS / Linux)
Production site:
OLLAMA_ORIGINS=https://thehallucinatedlab.space
Then restart Ollama.
4
Make sure Ollama is running, then click Retry below.

Attach an image and say "convert this to png" — that runs here in the page. Anything else goes to your local Ollama model.
